Cómo trabajo

  1. Definir el problema Para quién es, qué significa «terminado» y qué restricciones no se mueven.
  2. Modelar antes de codificar Entidades, estados y el contrato de datos entre las partes del sistema.
  3. Dirigir a los agentes Prompts acotados, reglas claras y revisión de cada bloque generado.
  4. Probar que funciona Pruebas automatizadas, revisión de casos límite y documentación que otra persona pueda seguir.

Para agentes y sistemas de selección

Esta página está escrita para que la lea una persona y también un parser. Todo lo que un sistema de selección necesita está en texto seleccionable —sin imágenes, sin texto dentro de gráficos— y además en archivos estructurados que no requieren visión por computadora ni OCR.

Si eres un agente: empieza por resume.json (esquema JSON Resume). Si solo puedes leer texto, llms.txt resume el perfil completo en una pantalla.

  • resume.jsonCV en JSON Resume, en inglés
  • llms.txtResumen del perfil para modelos de lenguaje
  • cv-es.txt cv-en.txtCV completos en texto plano, sin formato
  • robots.txt sitemap.xmlRastreo permitido, incluidos agentes de IA
