# scp-00.github.io

Portafolio de una página. Publicado con GitHub Pages en https://scp-00.github.io/

Contenido:

- `index.html` — portafolio bilingüe (ES/EN), sin dependencias ni build.
- `resume.json` — CV en esquema JSON Resume, para agentes.
- `llms.txt` — resumen del perfil para modelos de lenguaje.
- `cv-es.txt` y `cv-en.txt` — CV en texto plano.
- `robots.txt` y `sitemap.xml` — rastreo e indexación.

Para editar el CV o el perfil, cambia el archivo fuente en el repositorio local y
vuelve a publicar. No requiere Jekyll: el sitio es HTML estático (`.nojekyll`).
